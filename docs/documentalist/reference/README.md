# Akasha website and release mirror

The Akasha website is a static GitHub Pages site. It presents the product, documentation, downloadable release assets, and the skills and plugins catalogs.

## Preview and data sources

Serve the repository root over HTTP with npx serve . -p 3000 or python3 -m http.server 3000. The release and skills pages load JSON. The plugins page retrieves its catalog from a CDN.
