          <h2>MCP — validate and probe</h2>
          <p>Akasha ships <strong>offline JSON validation</strong> and a short <strong>stdio JSON-RPC probe</strong> (<code>initialize</code>, optional <code>tools/list</code>) before you rely on a server.</p>
          <ul>
            <li>CLI: <code>akasha mcp validate &lt;mcp.json&gt;</code> · <code>akasha mcp probe &lt;mcp.json&gt; [--name SERVER] [--tools]</code></li>
            <li>API: <code>GET /api/mcp/status</code> (disk validation) · <code>GET /api/mcp/runtime</code> (stdio attach summary) · <code>POST /api/mcp/runtime/stdio/start</code> / <code>POST /api/mcp/runtime/stdio/stop</code> (optional long-lived child for operators).</li>
            <li>Docs: <a href="https://github.com/azerothl/Akasha/blob/main/spec/dev/integrations/mcp-mvp.md" target="_blank" rel="noopener">mcp-mvp.md</a>, <a href="https://github.com/azerothl/Akasha/blob/main/spec/dev/integrations/mcp-runtime.md" target="_blank" rel="noopener">mcp-runtime.md</a>, <a href="https://github.com/azerothl/Akasha/blob/main/spec/dev/integrations/mcp-oauth.md" target="_blank" rel="noopener">mcp-oauth.md</a> (OAuth hardening checklist).</li>
