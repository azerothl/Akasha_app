          <h2>Migration &amp; multi-repo ecosystem</h2>
          <p>Akasha splits <strong>execution</strong> (Rust daemon) from <strong>catalogues and docs</strong>:</p>
          <ul>
            <li><strong>Skills</strong> — <a href="https://github.com/azerothl/Akasha_skills" target="_blank" rel="noopener">Akasha_skills</a> (gallery + <code>skills.json</code> synced to this site).</li>
            <li><strong>Plugins</strong> — <a href="https://github.com/azerothl/Akasha_plugins" target="_blank" rel="noopener">Akasha_plugins</a> + WASM install under your data directory.</li>
            <li><strong>Code Studio</strong> — <a href="https://github.com/azerothl/akasha-code-studio" target="_blank" rel="noopener">akasha-code-studio</a> web cockpit for project tasks (see <code>docs/OPERATOR_COCKPIT.md</code> in that repo).</li>
            <li><strong>Local inference</strong> — <a href="https://github.com/azerothl/Rbitnet" target="_blank" rel="noopener">Rbitnet</a> (OpenAI-compatible; wire in <code>llm_router.yaml</code>).</li>
          </ul>
          <p>When importing settings from another assistant, prefer <code>akasha config validate</code> and the vault for secrets — never commit API keys to this static site.</p>
        </article>
