          <p><strong>Delegation aliases:</strong> the agent id <code>code</code> resolves to the <code>code_generation</code> route; <code>search</code> resolves to <code>conversation</code>. There is no separate <code>task_types.search</code> key unless you add one yourself.</p>
          <p><strong>Autonomous mission</strong> (<code>autonomous_mission.yaml</code>) accepts additional <strong>heartbeat</strong> symbols such as <code>search</code>, <code>code</code>, <code>schedule</code> for <code>heartbeat_preferred_task_type</code> — routing still uses the mappings above (e.g. <code>code</code> → <code>code_generation</code>).</p>

          <h4>Structure of each <code>task_types.&lt;name&gt;</code></h4>
          <ul>
            <li><strong><code>primary</code></strong> — <code>provider</code>, <code>model</code>, optional <code>config</code> (see below).</li>
            <li><strong><code>fallback</code></strong> — ordered list of <code>{ provider, model, config? }</code>.</li>
            <li><strong><code>constraints</code></strong> — optional <code>max_cost_per_request</code> (USD), <code>max_latency_secs</code>.</li>
          </ul>
