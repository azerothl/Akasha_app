        <article class="docs-article" id="installation">
          <h2>Installation</h2>
          <h3>Requirements</h3>
          <ul>
            <li>OS: Windows 10+, macOS 11+, or Ubuntu 20.04+</li>
            <li><strong>Embedded model by default</strong> — no external installation required for core use. Ollama and cloud providers (OpenRouter, OpenAI) are optional; configure them during <code>akasha init</code> if you want to use them.</li>
          </ul>
          <h3>One-line install</h3>
          <p>Paste one of these commands in your terminal to download, install, and configure Akasha (daemon auto-start and optional config wizard).</p>
          <p><strong>Windows</strong> (PowerShell):</p>
          <pre><code>powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/azerothl/Akasha_app/main/scripts/get-akasha.ps1 | iex"</code></pre>
          <p><strong>Linux / macOS</strong>:</p>
          <pre><code>curl -sSL https://raw.githubusercontent.com/azerothl/Akasha_app/main/scripts/get-akasha.sh | bash</code></pre>
          <h3>Download (manual)</h3>
          <p>Go to the <a href="releases.html">Releases</a> page on this site or <a href="https://github.com/azerothl/Akasha_app/releases" target="_blank" rel="noopener">GitHub Releases (Akasha_app)</a> — <strong>binaries are published here</strong> (public mirror). For a complete install, download <strong>akasha-full-&lt;os&gt;</strong> (CLI + daemon + TUI + desktop bundle + scripts). Extract to e.g. <code>C:\Akasha</code> or <code>~/Akasha</code>.</p>
          <p><strong>Windows:</strong> double-click <code>INSTALL.cmd</code> at the root of the extracted folder to run the installer (no PowerShell execution policy prompt), or run <code>.\scripts\setup.ps1</code>. <strong>Linux / macOS:</strong> run <code>chmod +x scripts/setup.sh &amp;&amp; ./scripts/setup.sh</code>.</p>
          <p>You get the <code>akasha</code> (or <code>akasha.exe</code>), <code>akasha-daemon</code>, <code>akasha-tui</code> executables, a <code>docs</code> folder with the user guide, and in the full zip a <code>ui</code> subfolder with the desktop app installer.</p>
