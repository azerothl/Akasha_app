0</strong>). First load of the embedded model can be slow—increase if needed.</li>
            <li><code>AKASHA_LLM_STREAM_IDLE_SECS</code> — Max gap between stream chunks (default <strong>60</strong>).</li>
            <li><code>AKASHA_LLM_FIRST_CHUNK_SECS</code> — Max wait for the <em>first</em> chunk (embedded model load); defaults to <code>min(300, AKASHA_LLM_TIMEOUT_SECS)</code>.</li>
            <li><code>AKASHA_MAX_TOOL_ROUNDS</code> — Agent tool loop iterations per reply (default <strong>10</strong>).</li>
            <li><code>AKASHA_EMBEDDED_MODEL</code> — Embedded backend id (e.g. <code>qwen3_0_6b</code>; build-dependent).</li>
            <li><code>OLLAMA_HOST</code> — Ollama base URL (default <code>http://localhost:11434</code>) if not in <code>llm_router.yaml</code>.</li>
          </ul>

          <h3>Orchestration &amp; session limits</h3>
          <ul>
            <li><code>AKASHA_MAX_CONCURRENT_DELEGATIONS</code> — Parallel sub-tasks (default <strong>15</strong>).</li>
            <li><code>AKASHA_MAX_PARALLEL_SUBTASKS</code> — Parallel LLM subtask workers (default <strong>4</strong>).</li>
            <li><code>AKASHA_MAX_COST_PER_SESSION_USD</code> — Stop chat session when estimated LLM cost exceeds this (optional).</li>
            <li><code>AKASHA_MAX_TOKENS_PER_SESSION</code> — Stop session when token usage exceeds this (optional).</li>
            <li><code>AKASHA_DEGRADED_MODE=1</code> — Router uses only local providers (e.g. Ollama + embedded).</li>
          </ul>
