<strong>Calendar</strong>, <strong>Memory</strong>. Use Tab to switch; R to refresh Router, Scheduled, or task list; F2 to cycle themes. <strong>Mission</strong> and full <strong>Settings</strong> are desktop/web only; you can still edit <code>autonomous_mission.yaml</code> or call the HTTP API from the CLI.</p>
          <p>The <strong>desktop app</strong> (Akasha UI, if installed) connects to the same daemon on port 3876 and adds: <strong>Settings</strong> with <strong>Agent profile</strong> (including <strong>formality</strong> — formal / informal / default), <strong>Data</strong> with <strong>User RAG</strong> and <strong>Project graph</strong> (multiple indexed folders, HTML report per workspace), <strong>Mission</strong> tab for autonomous goals, and <strong>attachments</strong> in Chat (images, PDFs, text).
