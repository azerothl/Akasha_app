        <article class="docs-article" id="update-api">
          <h2>Update API</h2>
          <p>Akasha checks the following endpoint on startup (if auto-update is enabled):</p>
          <pre><code>GET https://azerothl.github.io/Akasha_app/api/latest.json</code></pre>
          <h3>Response format</h3>
          <pre><code>{
  "version": "v0.10.0",
  "release_date": "2026-09-25",
  "release_notes_url": "https://azerothl.github.io/Akasha_app/releases.html",
  "download_url": "https://github.com/azerothl/Akasha_app/releases/tag/v0.10.0",
  "changelog": "…",
  "min_supported_version": "0.5.0"
}</code></pre>
          <h3>Version comparison</h3>
          <p>Akasha uses semantic versioning (<a href="https://semver.org" target="_blank" rel="noopener">semver</a>). An update is triggered when <code>version</code> in the response is greater than the installed version.</p>
          <p>Run <code>akasha update check</code> to see if a newer version is available; the command prints the download link.</p>
        </article>
